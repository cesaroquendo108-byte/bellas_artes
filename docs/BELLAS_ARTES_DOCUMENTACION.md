## Regla de lectura

El tablero decide si una función está verificada, preparada, bloqueada,
pendiente o histórica. Una UI o un manifest no demuestran que un workflow GPU
esté disponible para clientes.

No se guardan secretos, tokens, credenciales ni URLs privadas en esta
documentación.
