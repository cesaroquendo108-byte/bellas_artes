# Anima una imagen con I2V

Image to Video transforma una imagen guardada en el punto de partida de un movimiento. El archivo local sirve para preview; la generación real necesita un asset persistido.

## Describe movimiento, no apariencia

La imagen ya contiene la apariencia. El prompt debe concentrarse en acción, desplazamiento de cámara, ritmo y elementos que cambian con el tiempo.

## Mantén continuidad

Si utilizas un frame final, procura que conserve sujeto, iluminación y perspectiva compatibles con el inicio.
