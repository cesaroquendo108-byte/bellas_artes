# Anima una imagen con I2V

Imagen a video transforma una imagen guardada en el punto de partida de un movimiento. El archivo local sirve para una vista previa; la generación real necesita un recurso persistido.

## Describe movimiento, no apariencia

La imagen ya contiene la apariencia. La descripción debe concentrarse en la acción, el desplazamiento de cámara, el ritmo y los elementos que cambian con el tiempo.

## Mantén continuidad

Si utilizas un frame final, procura que conserve sujeto, iluminación y perspectiva compatibles con el inicio.
