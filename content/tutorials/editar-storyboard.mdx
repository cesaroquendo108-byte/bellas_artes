# Organiza escenas en Storyboard

El editor de Story mantiene una copia local mientras sincroniza el documento con Supabase.

## Flujo recomendado

1. Crea las escenas principales.
2. Añade y duplica planos para explorar alternativas.
3. Define duración, cámara y transición.
4. Comprueba el ritmo en Timeline.
5. Usa Preview para revisar la estructura completa.

Si la red falla, el borrador local permanece identificado como contenido pendiente de sincronización.
