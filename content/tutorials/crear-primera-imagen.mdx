# Crea tu primera imagen

Abre Image Studio y comienza con una descripción concreta del sujeto, la acción, el entorno y la luz.

## Configuración inicial

- Selecciona una relación de aspecto adecuada al destino.
- Usa referencias únicamente cuando aporten identidad o composición.
- Ajusta calidad y resolución según el uso final.
- Conserva el prompt si el proveedor todavía no está configurado.

## Antes de generar

Revisa que el prompt no esté vacío y que las referencias sean assets propios. La interfaz nunca descuenta créditos mientras no exista un proveedor real conectado.
